 # 🌌 Solar System Interactive Simulation
 
+A browser-based Solar System visualization made with **HTML, CSS, and JavaScript**. The scene represents the Sun, the eight planets, Earth's Moon, and their orbits. CSS supplies the visual model and animation; JavaScript (using jQuery) connects the on-screen controls to CSS classes that change the view.
 
-An interactive, browser-based 3D solar system simulation built with HTML, CSS, and JavaScript. Explore the planets of  solar system with real-time orbital animations, planetary data, and intuitive controls.
+> **Note:** This is an illustrative visualization, not a scale-accurate astronomical model or a physics simulation. The CSS scale presets are visual comparisons.
